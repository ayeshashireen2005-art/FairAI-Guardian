# ⚖️ FairAI Guardian

🚀 **Built for Solution Challenge 2026**

FairAI Guardian is an AI-powered system that detects and mitigates bias in machine learning models, ensuring fair and ethical decision-making in automated systems.

---

## 🎯 Problem Statement

AI systems are widely used in critical domains such as hiring, loan approvals, and healthcare. However, these systems often inherit biases from historical data, leading to unfair and discriminatory outcomes.

---

## 💡 Our Solution

FairAI Guardian provides a complete pipeline to:

- Detect bias in machine learning models  
- Measure fairness using statistical metrics  
- Apply bias mitigation techniques  
- Compare results before and after correction  

---

## 🚀 Features

- ⚠️ Bias Detection (Gender-based analysis)  
- 📊 Fairness Metrics (Disparity Ratio)  
- 🛠️ Bias Mitigation (Remove sensitive features)  
- 🔁 Before vs After Comparison  
- 🖥️ Interactive Dashboard (Streamlit)  

---

## 🧠 How It Works

1. Upload dataset  
2. Preprocess data (cleaning + encoding)  
3. Train machine learning model  
4. Detect bias using fairness metrics  
5. Apply bias correction techniques  
6. Retrain model and compare results  

---

## 📊 Results

| Metric | Before Fix | After Fix |
|------|-----------|-----------|
| Disparity Ratio | 0.34 ❌ | 0.94 ✅ |
| Accuracy | ~0.85 | ~0.84 |

✅ Significant improvement in fairness with minimal impact on accuracy
